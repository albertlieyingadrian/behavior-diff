description: "What did my fine-tune change? Named behavior changes, how often they happen and under which input conditions, tested against a same-model control."
---

You fine-tuned a model to do one thing. behavior-diff tells you what else changed.

It samples the base model and the fine-tune on the same prompts and asks a judge model how each pair of replies
differs. It then groups those descriptions into named behaviors, like "uses a concise response style" or "engages
empathetically", and counts how often each one points to each model. A sign test decides which behaviors really
changed. The same test runs on the base against itself, which shows you how much of the result is noise.

## Try it in one command

```bash
pip install bdiff
bdiff demo
```

The demo replays a real run with no API key, no GPU and no network: a Qwen3-8B LoRA trained on
[Tinker](https://thinkingmachines.ai/tinker/) to answer in bullet points. It finds the change as "Uses concise
response style … often in lists" (25 prompts against 10, q = 0.047), and the same-model control changes 0 of 14
categories. Or [open the notebook in Colab](https://colab.research.google.com/github/albertlieyingadrian/behavior-diff/blob/main/examples/quickstart.ipynb).

<Note>
  The package uses only the Python standard library. Backends for Tinker, vLLM on Modal and local transformers are
  optional extras. The tests run on a CPU in seconds, with saved data and a fake judge.
</Note>
